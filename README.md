# Network Attacks and Reconnaissance — Autumn 2025

My weekly homework/report repository for Tero Karvinen's *Network Attacks and Reconnaissance* course: https://terokarvinen.com

Over the course I worked hands-on with packet capture and analysis, RFID/NFC, wireless (WiFi) reconnaissance and attacks, and radio/signal basics, and documented each week's exercises as a report. All work was done in course lab and simulation environments.

The reports are written in Finnish. You can translate them with Google's page translator: https://translate.google.com/
